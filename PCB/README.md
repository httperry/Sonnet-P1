# PCB Layout

![Status](https://img.shields.io/badge/Status-In%20Progress-orange?style=flat-square)

This folder contains all the Printed Circuit Board(PCB) layout and routing files for Sonnet P1


## Design Constraints
 1) *Form Factor:* Low profile chest deployment (lapel device).
 2) *Dimensions:* 52 x 38 x 12 mm³ (Total device footpront).
 3) *Weight:* < 45g.
 4) *Routing Considerations:* High speed SPI/Chirp IF for the mmWave radar and SPI / ToF Data for the UWB transceiver,     alongside 4.2 MB internal contiguous SRAM AXI bus fabric management.


 **NOTE: PCB layout files are currently in progress and shall be updated with time**
